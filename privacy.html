PRIVACY POLICY

How VAYNTR's current website, browser demos, and third-party services handle information.

V

Last reviewed: October 15, 2026. This is a practical starting point, not legal advice or a guarantee of compliance. Review it against actual operations and applicable law before production launch.

1. Current operator and status

VAYNTR is an independent esports project using a static website hosted through GitHub Pages. This site does not identify a registered business entity or publish a dedicated private privacy-request email.

2. Data entered into demos

The recruitment form is a demo: submission displays an on-page message and does not send the entered fields to VAYNTR or store them in an application database. Do not enter real contact details or sensitive information. The settings demo and member-dashboard preview save values in browser local storage under vayntr-settings-profile and vayntr-member-dashboard-profile. These values are not synced to a verified account and may be accessible to others using the same browser profile.

3. Supabase and third parties

Some pages initialize a Supabase client using a public publishable key. Authentication, cloud profile synchronization, and membership verification are not yet connected to the site interface; this does not mean a secure member system is live. The browser may contact Supabase and a third-party JavaScript delivery host during initialization. GitHub Pages may process technical request data; Google Fonts requests font files from Google. External links have their own privacy practices.

4. Cookies, analytics, and advertising

VAYNTR does not intentionally run advertising trackers or a dedicated analytics product at the time of review. The demos use browser local storage. Revisit this statement before adding analytics, ads, marketing pixels, embedded media, or other tracking. See Cookies & Browser Storage.

5. Security and minimization

Do not submit sensitive information through demo features. Before production accounts or applications launch, document data collection, access controls, retention, deletion, backups, incident response, and lawful sharing. Database tables need appropriate Row Level Security and least-privilege permissions. A publishable key is not a security control; secret/service-role keys must never be placed in browser code.

6. Children and younger players

The current demo is not designed to collect children's personal information. Do not submit personal information if you are under 13. Before knowingly collecting information from children or recruiting younger players, VAYNTR must assess applicable child-privacy and consent requirements and implement suitable safeguards.

7. Choices and requests

Clear local values through your browser's site-data settings. Blocking Google Fonts may change the site's appearance. A dedicated private privacy-request channel is not configured. Do not post personal data, passwords, identity documents, or confidential evidence in public GitHub issues. Configure a monitored private contact method before collecting real applicant or account data.

8. Retention and changes

VAYNTR does not currently operate a production application database or cloud member-profile store through this site. Browser values remain until cleared or removed by the browser. This policy must be revised if VAYNTR begins storing applications, accounts, analytics, or partner-shared records.

9. Contact

For non-sensitive site issues, use the VAYNTR website repository. Do not post private information publicly.
