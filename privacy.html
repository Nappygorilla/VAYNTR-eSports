PRIVACY POLICY

How this static website handles browser settings, forms, and third-party services.

V

Last updated: October 15, 2026. This notice describes the current static website. If features or service providers change, this page must be updated.

1. Current site operation

VAYNTR is currently a static website hosted through GitHub Pages. It does not currently provide user accounts, a VAYNTR database, or a server-side application-submission service.

2. Settings saved in your browser

If you choose “Save local profile” in the settings demo, the site stores the selected game settings in your browser's local storage under the key vayntr-settings-profile. This data stays in that browser profile unless you clear it or browser settings remove it. The site does not send that profile to a VAYNTR server.

3. Recruitment form

The recruitment form is a demonstration only. Submitting it displays a message and does not send or store the information. Please do not enter real contact details or other personal information into the demo form.

4. Hosting and third-party services

The site is hosted by GitHub Pages. GitHub may process technical information, such as server logs and request metadata, under its own policies. The site also loads fonts from Google Fonts, which means your browser connects to Google to request those font files. Those providers process data according to their own terms and privacy notices.

Outbound links, including the separate Warzone Performance Lab, lead to other websites with their own practices. Review their policies before using them.

5. Cookies and tracking

The current site does not intentionally run advertising trackers or analytics scripts. The settings demo uses local storage, which is browser storage rather than a server account. Hosting providers or linked services may use their own technologies as described in their notices.

6. Children and personal information

Do not submit sensitive or unnecessary personal information through demo features. Before adding accounts, analytics, applications, or other collection features, the site owner should review applicable child-privacy and data-protection requirements and update this policy.

7. Your choices

You can clear the site's local settings by clearing this website's browser storage. You can also block third-party font requests through browser controls, though the appearance may change.

8. Changes and contact

This notice must be reviewed whenever the site's data practices change. For questions or corrections, use the repository's issue/contact facilities at the VAYNTR website repository ↗. Do not post private information publicly.
